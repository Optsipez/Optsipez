### Stuff I've actually shipped

**[Inventory Intelligence Platform](https://github.com/Optsipez/item-report-prototype)**
Real-time item lookup and reporting on top of a retailer's Navision sales data — resizable columns, live sorting, rolling sales averages computed on load. This is the one eating all my commits right now.
`JavaScript`

**[AI Real Estate Agent](https://github.com/Optsipez/AI-RealEstate-Agent)**
An AI calling agent trained on UAE real estate listings — picks up, talks property, doesn't get tired of the same question forty times a day.

**[Khaleej Gamers](https://github.com/Optsipez/khaleej-gamers)**
Migrated a friend's UAE gaming-hardware store off Shopify onto a React + Flask + SQLite stack I self-host — no more platform cut, no more platform limits.
`JavaScript`

**[After-School Classes Platform](https://github.com/Optsipez/afterschoolclassesvue) + [Backend](https://github.com/Optsipez/after-school-classsesbackend)**
A Vue front end talking to a Node backend so parents can actually browse and book classes without six phone calls.
`Vue.js` `Node.js`

**[AI Plant Disease Detection](https://github.com/Optsipez/AI-Plant-Disease-Detection)**
Deep learning model that reads a photo of a leaf and tells you what's wrong with it.
`Jupyter Notebook`

**[Autonomous Farming Robot](https://github.com/Optsipez/Autonomous-Farming-Robot)**
